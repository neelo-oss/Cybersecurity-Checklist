# Cybersecurity-Checklist

A short and simple, easy to follow cybersecurity checklist for students and staff alike.

## CHECKLIST
Includes useful points to consider anytime you:

- Are using the internet

- Receive emails from unkown/suspicious addresses

- Unusual text messages from organizations/businesses
